# 東京次発

Even Realities G2 向けの、駅時刻表カウントダウンアプリです。
近くの駅と方面を選ぶと、次の電車の発車時刻までの残り時間を G2 に表示します。

- [プライバシーポリシー](privacy-policy.md)
- [Privacy Policy (English)](privacy-policy.en.md)
- [ソースコード](https://github.com/iinuma/tokyojihatsu)

## 対応範囲

公共交通オープンデータセンター（ODPT）が駅時刻表を提供している 7 事業者 440 駅。

東京メトロ / 都営（都電荒川線・日暮里舎人ライナーを含む） / 横浜市営 /
つくばエクスプレス / 多摩都市モノレール / ゆりかもめ / りんかい線

JR東日本・京急・東急・京王・小田急・西武・東武・相鉄は、ODPT に駅時刻表が
提供されていないため対応していません。
